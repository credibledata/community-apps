2026 Midterms Simulation Explorer · Data as of Nov 2, 2026

A Monte Carlo simulation of all 506 races on the 2026 ballot, run 10,000 times from public polls, prediction-market prices, past results, and demographics. Each run is one potential set of outcomes; the charts show how often each result occurs in this model. Change the assumptions to see how the results change.

Data sources and methodology · Election night results · A demonstration of a Malloy semantic model and an HTML data app, built with Credible Publisher.

This is an educational simulation, not a prediction or an endorsement of any candidate or party. Its results depend on the assumptions shown, all of which can be changed above.

Data as of the date above, from Wikipedia (races, incumbents and Sabato's Crystal Ball ratings; CC BY-SA 4.0), VoteHub (polls), FiveThirtyEight (pollster ratings; CC BY 4.0), The Downballot (district results and special elections), MIT Election Data and Science Lab (state results), the U.S. Census Bureau (ACS demographics), the FEC (fundraising) and Kalshi (market prices). House effects and the approval average are calculated here. This project is independent and is not affiliated with or endorsed by any of these sources, raters, or markets.
